# Post-1.0 idea archive

Nothing in this directory is a release requirement. These ideas may be
reconsidered only after 1.0 ships and only when the finished game demonstrates
a real need for them.

The old specifications remain available in the dated archive; this page keeps
the deferred themes visible without carrying their detail into the active
contract.

## Deferred expansion themes

- Additional playable courts and scenario starts beyond the Ugarit campaign.
- Much larger population and settlement counts after profiling proves they
  improve play rather than merely advertise scale.
- Named ships, crews, hull condition, broader caravan organizations, maritime
  insurance, and more elaborate credit instruments.
- Wider commodity chains, workshops, professions, animal systems, and regional
  price behavior.
- Large-scale coalition warfare, siege, mass displacement, refugee settlement,
  and long occupation systems beyond what the Ugarit campaign needs.
- Procedurally generated institutions, settlements, dynasties, and long
  succession histories.
- Modding, scenario editors, alternate palettes, additional language packs,
  and broader model choices.
- More elaborate diplomatic ceremony, translation, scribal schools, tablet
  manufacture, libraries, and archaeological afterlives.
- Spectator, export, chronicle, and comparative-run tools beyond the release
  archive and epilogue.

## Rules for revival

A deferred idea returns to active planning only if it:

1. creates recurring decisions in the shipped game;
2. interacts with at least two existing foundations;
3. has a natural home in an existing room or object type;
4. can be explained, tested, and balanced;
5. does not recreate duplicate systems or text overload;
6. is written into a new post-release specification before implementation.

“It would be realistic” is not sufficient by itself.
